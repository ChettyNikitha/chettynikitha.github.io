03 — Self-Built Demo Project

Kalshi-MarketLake

Built outside of work, end to end, to prove the same patterns above weren't a fluke: a production-shaped ETL pipeline against Kalshi's live trading API — extract → partitioned data lake → Postgres warehouse → FastAPI — with its own operator dashboard for watching the pipeline run.

case study

From a live prediction-market API to a queryable warehouse

Kalshi is a regulated exchange where contracts settle on real-world events. This pipeline pulls its events and markets, lands them immutably in a partitioned data lake, and loads a Postgres warehouse that a FastAPI app serves — nothing in the API layer ever calls Kalshi directly.
